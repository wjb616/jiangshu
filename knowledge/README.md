## 知识卡

`cards/injection-defect-cards.md` 共 15 张，覆盖注塑最常见的缺陷类型：

缩水、飞边、银纹、翘曲、短射、气泡/真空泡、熔接线、黑点、顶白、拉丝、色差、粘模、喷射纹、流痕、尺寸不稳。

每张卡的固定结构：

```
## C0X 缺陷名（别名 / English）

**别名**：现场口语叫法
**现象**：一句话能对上车间
**常见原因**：（按出现概率排序，不是罗列）
**排查顺序**：先查什么后查什么
**调整方向**：往哪个方向调
**注意**：容易搞反的地方
**核实状态**：待一线核实 / 已核实（一线）/ 已核实（文献）
```

**格式要求**：

- 卡片之间用 `---` 分隔（Dify 分段依赖这个符号）
- 一张卡不要超过 600 字，超了就拆成两张
- 标题里必须带**所有常见叫法**——师傅说"熔接痕"，卡片只写"熔接线"，关键词通道就匹配不上

**内容来源**：注塑工艺通用教材、材料商公开加工指南、行业公开资料整理。

⚠️ **不是企业一手数据**。每张卡的「核实状态」字段就是为此保留的——答辩或对外说明时，必须如实标注来源类型。

处理流程：

```bash
pip install pymupdf

# 1. 清洗
python tools/clean_pdf.py "你的PDF目录" "输出目录"

# 2. 质量分类（乱码/扫描件会被挑出来）
python tools/check_quality.py "输出目录" --split

# 3. 统一重命名并按类型归档
python tools/organize.py "你的PDF目录" "输出目录"
```

第 3 步会生成 `01_清洗后文献/`，里面是按 `序号_类型_标题_年份.txt` 命名的文件，直接上传到 Dify 理论层知识库。

## 建库参数

| 库 | 分段模式 | 分隔符 | 长度 | 重叠 |
|---|---|---|---|---|
| 对策层 | 通用 | `---` | 1024 字符 | **0** |
| 理论层 | 父子 | 父 `\n\n` / 子 `\n` | 1024 / 256 | 50 / 0 |

⚠️ 两个库都必须**取消勾选「替换掉连续的空格、换行符和制表符」**。勾上会把 `\n\n` 和 `---` 一起压成空格，分隔符失效，整篇按长度硬切。
