## C01 缩水（缩痕 / 凹陷 / 瘪痕 / Sink Marks）

**别名**：缩痕、凹陷、瘪进去、收缩痕

**现象**：制品表面局部凹陷，多见于壁厚突变处、加强筋背面、柱位根部、螺柱周围。

**常见原因**（按出现概率排序）：

1. 保压压力不足或保压时间过短，熔体补缩不到位
2. 料温或模温偏高，冷却阶段体积收缩量大
3. 壁厚不均，厚壁区冷却慢、收缩集中在厚壁侧
4. 浇口过小或过早冻结，通道关闭后无法继续补料
5. 注射量设定偏小，保压阶段无料可补

**排查顺序**：保压（压力/时间）→ 模温（重点看厚壁区）→ 浇口与流道尺寸 → 制品结构壁厚设计。

**调整方向**：提高保压压力并延长保压时间；料温下调 5–10℃；厚壁区加强冷却或增设冷却水路；适当加大浇口。

**注意**：单纯提高注射速度通常无效，反而可能加剧内应力与飞边。加强筋厚度一般控制在主壁厚的 50%–60%，超过则筋背面必缩。

**核实状态**：待一线核实

## C02 飞边（披锋 / Flash）

**现象**：制品分型面、镶件配合面、顶针孔边缘出现薄片状多余料。

**常见原因**（按出现概率排序）：

1. 锁模力不足，或锁模力分布不均
2. 注射压力或保压压力过高
3. 模具分型面磨损、变形或有异物
4. 料温过高，熔体流动性过强
5. 排气槽过深，熔体溢入排气通道

**排查顺序**：先算锁模力是否足够（投影面积 × 型腔压力）→ 再查分型面状态 → 再查压力设定 → 最后查料温。

**调整方向**：提高锁模力；降低保压压力；修模研磨分型面；料温下调；排气槽深度按材料调整（一般 0.02–0.03mm）。

**注意**：飞边与缩水常同时存在——为消除缩水而猛加保压，往往把飞边打出来。这两个缺陷要一起看，不能单点调。

**核实状态**：待一线核实

## C03 银纹（料花 / Silver Streaks）

**现象**：制品表面沿流动方向出现银白色条纹，多在浇口附近或厚壁区。

**常见原因**（按出现概率排序）：

1. **原料未充分干燥**，水分在料筒内汽化（最常见，尤其 PA、PC、ABS）
2. 料温过高导致材料分解，产生气体
3. 螺杆转速过高，剪切过热
4. 背压过低，料筒内卷入空气
5. 排气不良，气体无法排出
6. 再生料比例过高或混入异料

**排查顺序**：**先查干燥**（干燥温度/时间/干燥机状态）→ 再查料温与螺杆转速 → 再查背压 → 最后查排气。

**调整方向**：按材料要求重新干燥（PA 类通常需 80–100℃、4 小时以上）；降低料温；降低螺杆转速；适当提高背压；清理或加深排气槽。

**注意**：银纹和黑点常同源，都是"料出了问题"。遇到这两类缺陷，先别调机，先查料。

**核实状态**：待一线核实

## C04 翘曲变形（Warpage）

**现象**：制品脱模后弯曲、扭曲，或平面度超差，冷却后逐渐显现。

**常见原因**（按出现概率排序）：

1. 冷却不均——动定模温差大，或厚薄区域冷却速率差异大
2. 收缩不均——流动方向与垂直方向的收缩率差异（尤其玻纤增强料）
3. 保压不均，各型腔或各区域补料量不一致
4. 浇口位置不当，流动比过大导致末端压力衰减
5. 脱模过早，制品未充分冷却即顶出
6. 顶出受力不均

**排查顺序**：模温分布（动定模分别测）→ 冷却时间是否足够 → 保压是否平衡 → 浇口位置与流动比 → 顶出系统。

**调整方向**：平衡动定模温差（一般控制在 5℃ 以内）；延长冷却时间；调整保压曲线；玻纤料注意浇口位置与纤维取向；必要时做模流分析预判。

**注意**：翘曲是最难调的缺陷之一，因为它往往在脱模后几小时才完全显现。**判断效果必须等 24 小时后再测尺寸**，当天测会误判。

**核实状态**：待一线核实

## C05 短射（缺料 / Short Shot）

**现象**：制品末端、薄壁处或远离浇口的位置填充不满，边缘圆钝。

**常见原因**（按出现概率排序）：

1. 注射量不足或注射压力不足
2. 注射速度过慢，熔体在充满前已冷却
3. 料温或模温偏低，流动性差
4. 流道、浇口截面过小
5. 排气不良，气体受阻形成反压
6. 壁厚过薄或流动比超出材料许可范围

**排查顺序**：注射量是否够（看余料）→ 注射速度 → 料温模温 → 浇口尺寸 → 排气。

**调整方向**：加大注射量；提高注射速度（薄壁件尤其有效）；料温上调 5–10℃；模温上调；加大浇口；增设排气。

**注意**：短射和飞边是同一枚硬币的两面——工艺窗口往往很窄。若两者反复交替出现，说明模具本身（浇口/排气/壁厚）有问题，靠调机解决不了。

**核实状态**：待一线核实

## C06 气泡与真空泡（Voids / Bubbles）

**现象**：制品内部或厚壁处出现气泡。表面可见的多为气体，内部大空洞多为真空泡（收缩孔）。

**常见原因**（按出现概率排序）：

1. **真空泡**：厚壁区外表先冷却定型，内部继续收缩形成负压空洞——本质是补缩不足
2. **气体泡**：原料含水或分解产气
3. 背压过低，料筒内卷入空气
4. 注射速度过快，熔体前沿卷气
5. 排气不良

**排查顺序**：**先判断是气泡还是真空泡**（切开看：内壁光滑为真空泡，有气体痕迹为气泡）→ 真空泡查保压，气泡查干燥与背压。

**调整方向**：

- 真空泡：提高保压压力、延长保压时间、降低料温、加强厚壁区冷却
- 气泡：彻底干燥原料、提高背压、降低注射速度、改善排气

**注意**：判断错误会导致方向完全相反——真空泡加大保压有效，气体泡加大保压反而更糟。这是新手最容易搞反的一处。

**核实状态**：待一线核实

## C07 熔接线（熔接痕 / 夹水纹 / 合模线 / Weld Lines）

**别名**：熔接痕、夹水纹、合模线、结合线（现场口语常混用）

**现象**：制品表面出现线状痕迹，多在孔位、嵌件、多浇口汇合处。

**常见原因**（按出现概率排序）：

1. 熔体分流后汇合，两股料前沿温度已降低，未能充分熔合
2. 料温或模温偏低
3. 注射速度过慢，前沿冷却过快
4. 汇合处排气不良，夹入气体
5. 色母或添加剂影响熔合强度

**排查顺序**：模温（汇合区）→ 料温 → 注射速度 → 汇合处排气 → 浇口位置。

**调整方向**：提高模温（对熔接线改善最明显）；提高料温；加快注射速度；在汇合处增设排气或溢料井；调整浇口位置使熔接线移到非外观面。

**注意**：熔接线不只是外观问题，更是**强度薄弱点**。结构件上的熔接线位置要在设计阶段就规划好，不能等到试模才处理。

**核实状态**：待一线核实

## C08 黑点与焦痕（Black Spots / Burn Marks）

**现象**：制品表面出现黑色颗粒、条纹，或局部焦黄、烧焦。

**常见原因**（按出现概率排序）：

1. 料筒或螺杆死角积料，长期受热碳化后脱落
2. 热流道存在死角或温控失灵
3. 料温过高或滞留时间过长导致分解
4. 排气不良，气体被绝热压缩烧焦（多在末端）
5. 再生料或环境中混入杂质
6. 射嘴与模具接触面不洁

**排查顺序**：清理料筒与螺杆 → 检查热流道温度与死角 → 核对料温与周期 → 检查排气 → 检查原料洁净度。

**调整方向**：彻底清机（用专用清洗料）；降低料温；缩短停留时间；增大排气；加装料斗磁选与防尘。

**注意**：黑点是**典型的"越调越糟"缺陷**——继续生产只会带出更多碳化物。正确做法是立刻停机清机，而不是调整参数硬撑。

**核实状态**：待一线核实

## C09 顶白与顶裂（Ejector Marks / Cracking）

**现象**：顶针位置发白、凸起，严重时出现裂纹或顶穿。

**常见原因**（按出现概率排序）：

1. 脱模阻力过大（脱模斜度不足、表面拉伤、真空吸附）
2. 顶出力不均或顶针面积过小
3. 模温偏低，制品刚性大不易脱模
4. 保压过大导致制品与模腔贴合过紧
5. 冷却时间不足，内部未定型即顶出

**排查顺序**：脱模斜度 → 模温 → 顶出系统（顶针数量/面积/平衡）→ 保压 → 冷却时间。

**调整方向**：加大脱模斜度（一般 ≥1°）；提高模温；增加顶针或加大顶针面积；降低保压；延长冷却时间；型腔表面抛光。

**注意**：顶白是应力发白的可见信号——**即使没顶裂，制品内部也已有残余应力**，后期可能在使用中开裂。不能只当外观问题处理。

**核实状态**：待一线核实

## C10 拉丝与拖痕（Stringing / Drag Marks）

**现象**：开模时浇口处拉出丝状料，或在制品侧面出现拖擦痕迹。

**常见原因**（按出现概率排序）：

1. 料温或喷嘴温度过高，熔体粘度过低
2. 抽芯或开模动作与熔体断料不同步
3. 喷嘴孔径过大或接触不良
4. 保压结束后未做射退（松退）
5. 侧壁有倒扣或表面粗糙导致拖伤

**排查顺序**：喷嘴温度 → 射退设定 → 开模与抽芯时序 → 模具侧壁状态。

**调整方向**：降低喷嘴温度 5–10℃；启用射退（松退）并调整距离；优化开模延时；抛光侧壁、修正倒扣。

**注意**：拉丝多发生在**易分解材料**（如 PVC、POM）上，这类材料对温度和停留时间极敏感，宁可低温慢注，不可高温快注。

**核实状态**：待一线核实

## C11 色差（Color Variation）

**现象**：同批制品之间或与标准色板之间存在色相、明度、饱和度差异。

**常见原因**（按出现概率排序）：

1. 色母或色粉分散不均，混料时间不足
2. 料温波动，导致色母分解程度不一致
3. 螺杆残留前一批料，换色未清干净
4. 再生料比例不稳定
5. 模温或冷却速度差异影响表面光泽，视觉上形成色差
6. 色母批次差异

**排查顺序**：混料工艺 → 料温稳定性 → 换色清机 → 再生料配比 → 模温一致性 → 色母批次。

**调整方向**：延长混料时间；稳定料温（检查加热圈与热电偶）；换色时用清洗料彻底清机；固定再生料比例；统一模温。

**注意**：色差判断需要**标准光源箱**，车间日光灯下判断会误判。答辩演示时若涉及颜色，要说明测量条件。

**核实状态**：待一线核实

## C12 粘模与拉伤（Sticking / Scuffing）

**现象**：制品粘在型腔或型芯上不易脱模，强行脱模后表面出现拉伤痕迹。

**常见原因**（按出现概率排序）：

1. 脱模斜度不足或型腔表面粗糙
2. 模温过高，制品尚未定型
3. 保压压力过大、时间过长，制品过度贴合
4. 模具排气不良形成真空吸附
5. 材料本身粘模倾向（如软质 PVC、TPE）

**排查顺序**：脱模斜度与表面 → 模温 → 保压 → 排气（是否形成真空）→ 材料特性。

**调整方向**：加大斜度、抛光型腔；降低模温；降低保压；增设排气或顶出时破真空；必要时用脱模剂（但会影响后续工序，慎用）。

**注意**：脱模剂是**最后手段**，残留会影响印刷、喷涂、焊接等后工序。能在模具上解决的问题不要靠脱模剂。

**核实状态**：待一线核实

## C13 喷射纹（蛇形纹 / 喷射痕 / Jetting）

**别名**：蛇形纹、蛇形痕、喷射痕、射纹

**现象**：从浇口起出现蛇形或波浪形痕迹，多在浇口正对空腔的位置。

**常见原因**（按出现概率排序）：

1. 浇口截面过小，熔体以高速射入空腔而非扩展流动
2. 注射速度过快
3. 料温偏低，熔体粘度高
4. 浇口正对型腔大空间，无缓冲结构

**排查顺序**：浇口尺寸 → 注射速度（分段）→ 料温 → 浇口位置与方向。

**调整方向**：加大浇口；降低初始注射速度（采用分段注射，先慢后快）；提高料温；改变浇口方向使熔体撞击型壁后扩散。

**注意**：喷射纹一旦形成是**不可逆的外观缺陷**，只能通过工艺与模具解决，不能后处理修补。

**核实状态**：待一线核实

## C14 流痕（波纹 / 水波纹 / Flow Marks）

**别名**：波纹、水波纹、流纹、年轮纹

**现象**：制品表面出现以浇口为中心的波纹状或年轮状痕迹。

**常见原因**（按出现概率排序）：

1. 料温或模温偏低，熔体前沿过早冷却
2. 注射速度过慢，前沿推进不连续
3. 浇口截面过小
4. 模具表面粗糙或排气不良

**排查顺序**：模温 → 料温 → 注射速度 → 浇口尺寸 → 模具表面。

**调整方向**：提高模温（对流痕改善最直接）；提高料温；加快注射速度；加大浇口；抛光模具表面。

**注意**：流痕与熔接线容易混淆——流痕是**以浇口为中心向外扩散的波纹**，熔接线是**两股料汇合的线状痕迹**。判断错了调整方向也不同。

**核实状态**：待一线核实

## C15 尺寸不稳定（Dimensional Instability）

**现象**：同一模具、同一参数下，制品尺寸批次间波动超出公差。

**常见原因**（按出现概率排序）：

1. 模温波动（冷却水温控制不稳）
2. 保压压力或时间不稳定
3. 原料批次差异（收缩率不同）
4. 冷却时间不足，脱模后继续收缩
5. 再生料比例变化
6. 设备重复精度不足

**排查顺序**：模温记录 → 保压曲线 → 原料批次 → 冷却时间 → 再生料配比 → 设备状态。

**调整方向**：加装模温机稳定水温；锁定保压参数并记录；固定原料供应商与批次；延长冷却时间；固定再生料比例。

**注意**：尺寸问题的排查必须**建立在数据记录上**——没有模温、保压、周期的连续记录，只能靠猜。企业做不好这一点，往往不是技术问题是管理问题。

**核实状态**：待一线核实
