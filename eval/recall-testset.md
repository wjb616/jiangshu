# 匠枢 · 知识库召回评测集 v0.1

> **用途**：每轮调整（分段、Embedding、TopK、阈值、Rerank）后跑一遍，记录命中情况，形成可对比的数据。
> **答辩价值**：这是"我们做过检索优化"的唯一硬证据。空口说做了混合检索没人信，有优化前后的命中率曲线才有说服力。

---

## 一、评分方法

每道题只看三个指标，不搞复杂的：

| 指标 | 判定 | 计分 |
|---|---|---|
| **命中** | TopK 结果里出现了期望卡片 | 1 分，否则 0 分 |
| **完整** | 命中的卡片包含「调整方向」，不是只命中「现象」 | 1 分，否则 0 分 |
| **无编造** | 回答没有出现知识库里不存在的数据（见第四部分陷阱题） | 1 分，否则 0 分 |

总分 = 命中数 / 题数。**优化前后的对比表比绝对分数更重要。**

## 三、复合题（区分度最高）

真实车间的问题很少只涉及一个缺陷，这类题最能看出检索能力。

| 编号 | 用户问题 | 期望命中 | 考察点 |
|---|---|---|---|
| Q16 | 边缘有飞边，但压力调低了又缩水 | C01 + C02 | **多卡召回**，是否同时给出两边 |
| Q17 | 银纹和黑点同时出现，先查哪个 | C03 + C08 | 同源判断（都是"料出了问题"） |
| Q18 | 加玻纤的料翘曲特别厉害 | C04（+ 材料特性） | 是否能关联纤维取向 |
| Q19 | 调高保压以后飞边更严重了怎么办 | C02 + C01 | 是否存在参数互斥的认知 |
| Q20 | 换了新批次的料，尺寸就不对了 | C15（+ 材料批次） | 跨库关联：论文库理论 + 卡片库对策 |

## 四、拒答题（防编造，答辩必演）

这类题**答案不在知识库里**，考察模型会不会硬编。

| 编号 | 用户问题 | 期望行为 |
|---|---|---|
| Q21 | 我们厂 280 吨的机器能打这个件吗 | 说明需要投影面积、型腔压力等条件，无法直接判断 |
| Q22 | 这个件保压应该设多少 MPa | 给出方向（提高/降低）与影响因素，明确说需试模确定，**不得给出具体数值** |
| Q23 | 你们给美的做过什么项目 | 明确说知识库无此信息，不编造客户案例 |
| Q24 | 2027 年注塑行业市场规模多少 | 说超出知识范围（知识库不含市场数据） |

**Q22 是最重要的一道。** 如果模型张口就来"保压 45MPa"，说明提示词约束失效，答辩时绝对会被评委抓住。要改到它会说"需要根据壁厚、流程比、材料流动性试模确定"为止。

## 六、怎么做对比实验（答辩用）

按这个顺序做，每步只改一个变量：

1. **基线**：纯向量检索，TopK 5，无 Rerank → 记录命中率
2. **+ 混合检索**（向量 0.7 / 关键词 0.3）→ 记录
3. **+ Rerank 模型** → 记录
4. **+ 元数据过滤**（按材料筛选）→ 记录

四行数据画成一张折线图，就是"我们通过三轮优化把召回准确率从 X% 提升到 Y%"。

**这张图比任何形容词都有用。** 评委问"你怎么证明有效"，你直接翻到这页。
