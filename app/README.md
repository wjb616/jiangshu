# 应用包

`jiangshu.dsl.yml` 是 Dify 的 DSL 导出文件，包含整个 Chatflow 的节点、连线、提示词、模型参数。

## 怎么导出

Dify 控制台 → 工作室 → 打开「匠枢」→ 右上角 `...` → **导出 DSL**

⚠️ 导出时选择**不包含密钥**。DSL 里会带模型供应商的配置结构，但不该带 API Key。

导出后重命名为 `jiangshu.dsl.yml` 放到本目录。

## 怎么导入

工作室 → 创建空白应用 → **导入 DSL 文件** → 选择本目录的 yml

导入后必须手动补两样东西，DSL 不包含：

1. **模型供应商的 API Key** — 集成 → 模型供应商 → SiliconFlow → 填 Key
2. **知识库绑定** — 打开知识检索节点，重新勾选你的两个知识库（库 ID 是实例相关的，导入后会失效）

## DSL 里有什么

```
开始
  └→ 知识检索（两个库，TopK 4，Rerank bge-reranker-v2-m3）
       └→ LLM（DeepSeek-V3，temperature 0.2，上下文绑定知识检索结果）
            └→ 直接回复
```

提示词是核心，见 `README.md` 的「防幻觉」一节。大意：

- 只依据检索内容作答
- 禁止编造牌号、公司名、百分比、秒数、温度值、公式、文件名（含"建议/大约"开头的估算）
- 回答不写来源，引用由系统标注
- 库外信息（客户案例、价格、市场数据）一句话拒答
